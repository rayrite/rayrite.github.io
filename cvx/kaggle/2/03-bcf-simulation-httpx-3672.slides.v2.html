The entire brief: a title and five bullets

Server connection handling.

* Add `HTTPParser.keep_alive`.
* Server... always read request to completion on keep alives.
* `HTTPParser.complete` -> `.reset`
* Close streams on server exit.
* Don't raise `KeyboardException` on server exit.  ← [sic] — the issue says KeyboardException; the fix handles KeyboardInterrupt

Quirks worth knowing before you parse it

  • Mixed line endings: the header uses \n, the five bullets carry \r\n — a GitHub-export artifact. Normalize before splitting.
  • No traceback, no repro, no file names. Every symbol named here (HTTPParser) must be found in the code by the agent itself.
  • Ellipsis in the spec: "Server... always read" — the literal three dots are the issue author's, not an elision.

  • Node: { name, text, id } — text carries the symbol's full source, so the graph doubles as an offline code index.
  • Edge: { type, source, target, key } — e.g. type: "calls", httpx._content.Content → httpx._content.Content.encode.
  • Ids are fully qualified: httpx._parsers.HTTPParser.complete — the prefix is the tree split, for free.
