## 2. Summary of Live BCF `v2.1` Hardening Upgrades Applied to `2026-11-25_BCF_Dataset_RCA_and_DualTrack_Brain`

To guarantee that your current submission archives (`track_31b/submission_31b.zip` and `track_e4b/submission_e4b.zip`) handle every single issue above out of the box, we directly upgraded and re-validated the implementation in `deliverables/2026-11-25_BCF_Dataset_RCA_and_DualTrack_Brain/`:

1. **Added Pure In-Memory `assets/bootstrap.txt` Fallback (`#758547` Cure)**: Created `skills/bcf-spec/assets/bootstrap.txt` (`< 4,700` chars) in both `track_31b` and `track_e4b` and updated `SKILL.md` + `bcf_plan.md` so if `run_skill_script` returns `NO_CODE_EXECUTOR` or empty output on the private scorer, `bcf_plan` loads `assets/bootstrap.txt` via `load_skill_resource` (string-only schema, zero executor needed!) and materializes `.git/bcf/bcf.py` in 1 `run_command` call.
2. **Upgraded `{bcf_spec}` $\to$ `{bcf_spec?}` Optional State Templating (`#760126` Cure)**: Updated `track_31b/submission/prompts/solver.md` and `track_e4b/submission/prompts/solver.md` to use Google ADK's optional `{bcf_spec?}` syntax plus a `cat .git/bcf/spec_pin.md` check so `solver` can never crash with `KeyError` even if `bcf_plan` truncates.
3. **Auto-Remapped Non-Test `pytest` Paths (`#760595` Exit-Code-5 Cure)**: Added `resolve_pytest_targets()` in `bcf.py` so passing `src/pkg/mod.py` to `bcf.py verify` automatically resolves and runs `tests/test_mod.py` instead of returning `"no tests ran"`.
4. **Enforced `PYTHONPATH=/workspace/src:/workspace` & `tests/` Write-Protection (`#760595` & `HARNESS_README` §8.2)**: Added `py_env(r)` across `baseline` and `verify`, blocked `tests/` edits inside `cmd_patch`, and expanded `PROTECTED_FILES` to include `_swegemma_stubs.py` and `sitecustomize.py`.
5. **Self-Healing `.git/info/exclude` & `.pyc` Scrubbing**: Added `ensure_git_exclude(r)` in `bcf.py` so `__pycache__/` and `*.pyc` never pollute `changed_files` even in raw local Git repositories.
6. **Whole-Tree Orphan YAML & Multi-Model Scanner (`#758969` Cure)**: Upgraded `package_and_validate_bcf.py` to scan every `.yaml`/`.yml` anywhere in the archive for stray `agent.yaml` files or mismatched `model:` declarations.
