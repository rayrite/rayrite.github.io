# Tools

Scripts written and used for this package. All are Python 3 with the standard library only, except where noted. They take their paths as arguments and write only where told to.

| Script | Purpose | Usage | Status in this run |
| --- | --- | --- | --- |
| `remote_zip.py` | Lists a Kaggle dataset archive and extracts chosen members over HTTP range requests, so a multi-gigabyte dataset costs kilobytes when only its metadata is needed | `python -I remote_zip.py <owner/slug> <out_dir> [--list] [--max-member-mb N] <prefix>...` | Executed on the four held-out sets (task rows, validation files, 150 snapshots: 16 of OOD-45, 18 of OOD-B, 36 of FreshSWE-Py and 80 for the rotation panels); every extracted archive matched the published checksums where the set publishes them |
| `store_from_tgz.py` | Builds the brain's snapshot store (the layout `index_snapshots.py` writes) from local snapshot archives, keeping text source files and `.pyi` stubs only | `python -I store_from_tgz.py <bcf-brain/tools> <store> <tgz_dir>...` | Executed |
| `brain_probe.py` | Dry run of the helper on task snapshots: `map`, `plan` from a mechanical brief, `find`; compares the result with the gold patch | `python -I brain_probe.py --brain <bcf-brain> --helper LABEL=PATH --store <store> --tasks <tasks.jsonl> --only id,id --out <tsv> [--maps <tsv>] [--finds <dir>] --work <dir>` | Executed on the 70 candidate tasks and on the 80 rotation tasks, with both helpers (300 rows). Its `kind` column comes from the shipped helper's rules for both helpers, so take per-helper routes from `route_census.py`; always pass `--only` |
| `probe_report.py` | Table and summary from one or more `brain_probe.py` result files | `python -I probe_report.py <tsv>... [--md out.md]` | Executed |
| `route_census.py` | Category, domain and route that each helper's own rules produce for every statement of a pool (no repository needed) | `python -I route_census.py --brain <bcf-brain> --helper LABEL=PATH --set NAME=tasks.jsonl [--out tsv]` | Executed on four pools and on the 80 rotation tasks |
| `eval_localizer_fixed.py` | The brain's localizer evaluation with every entry of the top-file line counted | `python -I eval_localizer_fixed.py --brain <bcf-brain> --helper LABEL=PATH --data <store> --features <features.jsonl> --packs <packs> --tasks <tasks.jsonl> --out <json>` | Executed on the public 129 |
| `tier_census.py` | Difficulty tiers from the harness's own engine (`swegemma.difficulty`) | `python tier_census.py LABEL=tasks.jsonl... [--ids id,id] [--out tsv]` | Executed; needs an interpreter that has the harness packages installed, and run without `-I` |
| `panel_power.py` | Power of the paired sign test for a panel, through the 2026-11-24 package's `paired_power.py`, for 20 to 129 pairs | `python -I panel_power.py <paired_power.py> [--md out.md]` | Executed |
| `fsp_census.py`, `ood45_table.py` | Per-task facts of FreshSWE-Py and of the OOD sets (statement source, dates, fix size, baseline-independent fields) | `python -I fsp_census.py <tasks.jsonl> <splits.json> <out.tsv>`; `python -I ood45_table.py <tasks.jsonl> <out.tsv>` | Executed |
| `hf_census.py`, `lb_repos.py` | Census of a Hugging Face dataset through its parquet files, and a per-repository summary | `python hf_census.py <owner/name> <out_dir> <out.tsv>`; `python lb_repos.py <parquet> <min_tasks>` | Executed on `nebius/SWE-rebench-leaderboard`; needs `duckdb` |
| `build_portfolio.py` | Writes `portfolio/` (task rows, panel lists, alternates, reserve, confirmation panel) and the table fragments from the data | `python -I build_portfolio.py <research folder> <output folder>` | Executed; expects the scratch layout of this run under the research folder |
| `rotation_pool.py` | One row for every task of FreshSWE-Py: statement source, baseline outcome, fix size, test time, whether it is usable and where it is used; per-repository strata and the compiled packages of each task environment on standard output | `python -I -X utf8 rotation_pool.py <research folder> <package folder> <out.tsv>` | Executed; writes `data/rotation_pool.tsv` |
| `build_rotation.py` | Fills the rotation panels cell by cell (`select`, deterministic for a seed) and writes `portfolio/rotation_r1.jsonl` to `rotation_r4.jsonl`, the panel lists, `rotation_cells.tsv` and the table fragments (`report`) | `python -I -X utf8 build_rotation.py select <research folder> [--seed N] [--panels K]`; `python -I -X utf8 build_rotation.py report <research folder> <package folder>` | Executed with the default seed and four panels; its markdown tables go through a writer that derives each separator row from the header and stops on a row with another cell count |
| `rotation_facts.py`, `rotation_relaxed.py` | Measured numbers behind Document 09 on standard output: pool strata, repositories, sizes, cells, tiers; and what each cell has left when the size limits are relaxed | `python -I -X utf8 rotation_facts.py <research folder> <package folder>`; `python -I -X utf8 rotation_relaxed.py <research folder>` | Executed |
| `assemble_doc09.py` | Writes `09_Rotation_Panels.md` from the template in the research folder, with every inserted table computed from the files of the run | `python -I -X utf8 assemble_doc09.py <research folder> <package folder> <paired_power.py>` | Executed; expects `fragments/doc09_template.md` under the research folder |
| `repo_fragments.py` | Writes the repository table fragments and copies the evidence files into `data/` | `python -I repo_fragments.py <research folder> <output folder> <targets folder> <repos folder>` | Executed; expects the scratch layout of this run |
| `qc_tables2.py` | A second table check with an implementation independent of the brain's `tools/qc_tables.py` | `python -I qc_tables2.py <folder>` | Executed: 22 files, 96 tables, 0 defects; on the 2026-11-24 package 91 tables, 0 defects |
| `qc_counts.py` | Tables per file, for the QC report | `python -I qc_counts.py <folder>` | Executed |
| `count_cells.py`, `show_cells.py` | Cells per line of a table, and the cells themselves, to settle cell counts without counting by eye | `python -I count_cells.py <file> <from>-<to>...`; `python -I show_cells.py <file> <line>[,<line>...]` | Executed |

Notes:

- The editor replay used the brain's own `tools/replay_gold.py` and `tools/tools_materialize.py`, unchanged, on the stores built by `store_from_tgz.py`.
- On Windows, set `GIT_CONFIG_COUNT=1`, `GIT_CONFIG_KEY_0=core.longpaths` and `GIT_CONFIG_VALUE_0=true` in the environment before the replay; three snapshots have paths longer than 260 characters.
- `build_portfolio.py` holds the selection list of P20 and the one-line annotations; change the list there and re-run to regenerate the files.
- `build_rotation.py` holds the cells, the near repositories, the six excluded tasks and the seed. A fifth panel in the same recipe is not possible (Document 09, Section 8); for another shape, change `CELLS` and the limits in `rotation_pool.py`, then run `select` and `report`.
- Separators of markdown tables are not typed by hand anywhere in the generators: `build_portfolio.py` asserts their length against the header, and `build_rotation.py` derives them.
