2. Dual-Boot Setup Checklist: Step-by-Step

Step 2.1: Windows 11 Pre-Flight Preparations

  • Backup BitLocker Recovery Key: In Admin PowerShell, run manage-bde -protectors -get C:. Record the 48-digit key. Run Suspend-BitLocker -MountPoint "C:" -RebootCount 2.
  • Disable Fast Startup: In Admin PowerShell, execute powercfg /h off to prevent NTFS filesystem locking.
  • Shrink Volume in Disk Management: Open diskmgmt.msc, right-click C:, select Shrink Volume, enter 768000 MB (750GB), and click Shrink. Leave as Unallocated.
  • Create Bootable USB: Download Zorin OS 18.1 Core ISO. Flash using Rufus with Partition Scheme: GPT and Target System: UEFI (non CSM).

Step 2.2: MSI Click BIOS X Settings

Reboot PC and tap DEL to enter MSI Click BIOS X. Press F7 for Advanced Mode:
  • EXPO Memory Profile: Go to OC -> DRAM Setting -> Set EXPO to [Profile 1] (6000 MHz).
  • CPU Virtualization: Go to OC -> CPU Features -> Set SVM Mode to [Enabled].
  • Re-Size BAR & IOMMU: In Settings -> PCIe Sub-system, set Above 4G Decoding, Re-Size BAR, and AMD IOMMU to [Enabled].
  • Boot Mode: In Settings -> Boot, ensure Boot Mode Select is [UEFI]. Press F10 to save and restart.

Step 2.3: Zorin OS 18.1 Installation Procedure

  • Tap F11 during boot to open MSI Boot Menu. Select your UEFI Flash Drive.
  • In GRUB, select "Try or Install Zorin OS (modern NVIDIA graphics)" to load the RTX 5090 driver.
  • Check "Install third-party software for graphics and Wi-Fi" and "Download updates".
  • Choose "Install Zorin OS alongside Windows Boot Manager". Complete setup and restart.
  • If prompted on restart, select Enroll MOK -> Continue -> Yes -> enter your MOK password to bless NVIDIA drivers.

3. Native Zorin OS 18.1 Developer Toolchain

Execute the following commands in the Zorin OS Terminal (Ctrl + Alt + T) to establish the complete bare-metal AI development stack:

3.1 System Packages & Docker CE with NVIDIA Container Toolkit

# 1. Update packages and install build essentials
sudo apt update && sudo apt upgrade -y
sudo apt install -y build-essential cmake ninja-build git git-lfs curl wget jq unzip zip ripgrep ca-certificates software-properties-common
git lfs install

# 2. Install native Docker CE
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] https://download.docker.com/linux/ubuntu noble stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
sudo apt update && sudo apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin
sudo usermod -aG docker $USER

# 3. Install NVIDIA Container Toolkit (enables RTX 5090 in Docker sandboxes)
curl -fsSL https://nvidia.github.io/libnvidia-container/gpgkey | sudo gpg --dearmor -o /usr/share/keyrings/nvidia-container-toolkit-keyring.gpg
curl -s -L https://nvidia.github.io/libnvidia-container/stable/deb/nvidia-container-toolkit.list | sed 's#deb https://#deb [signed-by=/usr/share/keyrings/nvidia-container-toolkit-keyring.gpg] https://#g' | sudo tee /etc/apt/sources.list.d/nvidia-container-toolkit.list
sudo apt update && sudo apt install -y nvidia-container-toolkit
sudo nvidia-ctk runtime configure --runtime=docker
sudo systemctl restart docker

3.2 Native Visual Studio Code (.deb Repository)

Do NOT install VS Code from the Software Store via Flatpak/Snap. Flatpaks isolate VS Code from system paths, breaking Claude Code CLI integration. Install the native deb package: 
curl -fsSL https://packages.microsoft.com/keys/microsoft.asc | gpg --dearmor | sudo tee /usr/share/keyrings/packages.microsoft.gpg > /dev/null
echo "deb [arch=amd64,arm64,armhf signed-by=/usr/share/keyrings/packages.microsoft.gpg] https://packages.microsoft.com/repos/code stable main" | sudo tee /etc/apt/sources.list.d/vscode.list > /dev/null
sudo apt update && sudo apt install -y code

3.3 Node.js 22 LTS, Claude Code CLI & VS Code Extension

# Install Node.js 22 LTS via nvm
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
export NVM_DIR="$HOME/.nvm"
[ -s "$NVM_DIR/nvm.sh" ] && \. "$NVM_DIR/nvm.sh"
nvm install 22 && nvm use 22 && nvm alias default 22

# Install Anthropic Claude Code CLI
npm install -g @anthropic-ai/claude-code

# Install Official Claude Code Extension in VS Code
code --install-extension anthropic.claude-code
code --install-extension ms-python.python
code --install-extension redhat.vscode-yaml
code --install-extension ms-azuretools.vscode-docker

3.4 Python 3.11 Workspace, vLLM, Google ADK & swegemma

# Install uv package manager
curl -LsSf https://astral.sh/uv/install.sh | sh
source ~/.cargo/env

# Create workspace and virtual environment
mkdir -p ~/bcf_workspace && cd ~/bcf_workspace
uv python install 3.11
uv venv .venv --python 3.11
source .venv/bin/activate
echo "source ~/bcf_workspace/.venv/bin/activate" >> ~/.bashrc
