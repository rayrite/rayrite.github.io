# Test Plan — ScamShield demo app (functional matrix + expected results)

Created 2026-09-20 for pre-submission / pre-showcase verification. Covers
every surface of the app. Two layers:

1. **Automated suites** — run these first; they cover ~80% in minutes.
2. **Manual functional matrix** — per-surface walkthroughs with exact expected
   results, including the graceful-error paths and the Railway deployment.

Conventions: `LOCAL` = a server you start yourself; `RAILWAY` =
`https://cvx-001-scamshield-mvp-production.up.railway.app`. Never test against
a server someone else is using. On Windows, run Python with `PYTHONUTF8=1`
(console arrows otherwise crash cp1252).

---

## 1. Automated suites (run first)

### 1.1 `cli.py verify` — 91 expected-vs-actual checks

Requires a **demo-mode** server (the suite spends credits otherwise and skips
those checks — by design — so run it in demo for full coverage):

```bash
cd app
mv .env .env.hold                       # hold the key aside
(.venv/Scripts/python.exe -m uvicorn main:app --port 8111 > demo-8111.log 2>&1 &)
sleep 6
mv .env.hold .env                       # restore immediately
PYTHONUTF8=1 .venv/Scripts/python.exe cli.py verify --base http://127.0.0.1:8111
```

**Expected:** `RESULT: 91 passed, 0 failed`. Covers: health, diagnostics
beacon, feature flags, all 9 pages (incl. `/models`), UDL round-trip, **model
switching** (registry count 6, role split 4/2, invalid POSTs → 400, swap →
health/metrics reflect, restore), dynamic wiki/SPA menus, chat demo turns,
turn cap, waitlist round-trip, staged-check demo end-to-end.

Also valid against a **live** server (credit-spending sections print SKIP):

```bash
PYTHONUTF8=1 .venv/Scripts/python.exe cli.py verify --base <RAILWAY-URL>
```

### 1.2 `smoke_test.py` — job state machine end-to-end

Same demo server as 1.1 (`BASE` is hard-coded to `:8111`):

```bash
PYTHONUTF8=1 .venv/Scripts/python.exe smoke_test.py
```

**Expected:** last line `ALL PASS` (25 checks: 202 create → snap gate →
document → go → custom redirect → consolidate → done → report; 404/400/409

### 2.8 Graceful error paths (the demo-safety net)

Use `app/mock429.py` (in the repo) to replay z.ai's rate-limit shape:

```bash

(.venv/Scripts/python.exe mock429.py &)                                   # :8125
(ZAI_API_URL=http://127.0.0.1:8125/... .venv/Scripts/python.exe -m uvicorn main:app --port 8126 &)
# full value for ZAI_API_URL: http://127.0.0.1:8125/api/paas/v4/chat/completions
```

| # | Action | Expected |
|---|---|---|
| 40 | On :8126, run a check job | Status **error**; user text: `The AI service is at capacity right now — please retry in a minute` |
| 41 | Same job, `/api/jobs/{id}` | `error_detail` keeps the raw `ZaiError: … code 1302` for the operator |
