 Failure paths (all typed, all explained):
   · blocked                 → 1 jittered retry, then honest stop + Retry button
   · sign_in_required        → park; current-only report rendered w/ banner
   · [auth_expired/challenge]→ park; human next-action attached
   · layout_drift · parse_empty → MHTML retained → fix offline → cli replay
   · no_results              → terminal card; fix query

sequenceDiagram
  autonumber
  participant B as Browser
  participant R as router (node:http)
  participant O as orchestrator
  participant C as capture (Playwright/CDP)
  participant E as eBay

  B->>R: POST /api/jobs {query}
  alt a job is already running
    R-->>B: 409 {error:'busy'}
  else free
    R->>O: jobs.create()
    R-->>B: 202 {jobId, eventsUrl, statusUrl}
    B->>R: GET /api/jobs/:id/events (EventSource)
    R->>O: subscribe (SSE replay from job.json event log)
    O-->>B: :stage capture
    O->>C: launch context + facet=current
    C->>E: goto /sch/i.html?_nkw=...
    E-->>C: 200 DOM batches
    C-->>O: scroll {cards, target, scrolls}
    C->>C: settle (images+fonts+networkidle-bounded)
    C->>E: CDP Page.captureSnapshot(mhtml)
    C->>C: write MHTML → drop string · PNG · decoded HTML
    O-->>B: :facet current {cards:200}
    O->>C: facet=completed (adds &LH_Complete=1)
    C->>E: goto ...
    alt sign-in wall (≥ 2026-07-22)
      E-->>C: 302 → signin.ebay.com
      C-->>O: facet.sign_in_required
      O-->>B: :facet completed {sign_in_required}
    else open
      C->>E: CDP Page.captureSnapshot(mhtml)
      O-->>B: :facet completed {cards:200}
    end
    Note over O,C: facet=sold — same pattern
    O->>O: extract → relevance → analyze → report
    O-->>B: :stage report {bytes}
    O-->>B: :done {reportUrl}
    B->>R: GET /report/:id/
    R-->>B: 200 (serves ONLY jobDir/report/ subtree)
  end
