   scroll loop (evidence-gated):
      for k = 1..N:
        scrollBy(0, viewportH × U(0.9, 1.2))
        sleep U(600, 1200) ms
        cards = $$eval('li.s-card[data-listingid]').length
        if cards ≥ target (default 200, clamp 150–240) → break
        if stagnant 2 ticks → break early (mark facet.partial if ≥40)
      emit {facet, cards, target, scrolls} to SSE

                                             ▼
   settle (asserted, not timed):
      · every <img>.complete && naturalWidth > 0   (timeout-raced)
      · document.fonts.ready
      · one best-effort networkidle ≤ 8 s (never blocking)

                                             ▼
   capture (memory-critical):
      1) CDP Page.captureSnapshot({format:'mhtml'})
      2) writeFileSync IMMEDIATELY
      3) drop every reference (single string, no streaming variant)
      4) client.detach()
      5) page.screenshot({fullPage:true}) — sliced if > 16 384 px
      6) write decoded .html via lib/mhtml.js

                                             ▼
   provenance:
      SHA-256 every artifact
      recorded: capture timestamp, URL, JSONL response sidecar,
                console messages + page errors (drift signal)
