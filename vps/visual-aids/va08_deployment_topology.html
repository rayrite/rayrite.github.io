   Loopback-only bind ⇒ ZERO CSF firewall changes
     (loopback is not filtered by CSF inbound rules; public traffic enters
      only via Apache 80/443, which is already open)

   NO Passenger / Application Manager
     Phusion's Apache integration buffers responses on disk with no off switch
     → kills 3-minute SSE.  systemd it is.

   AutoSSL FIRST
     Issue cert BEFORE adding the proxy include — HTTP-01 DCV breaks once
     "/" is proxied.  Order matters: first ProxyPass match wins.
