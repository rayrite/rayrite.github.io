  │                           GitHub (private repo)                          │
  │                                                                          │
  │  main  ◀── commit (small, trunk-based) ◀── you (in VS Code)            │
  │   │                                                                      │
  │   │                                                                     │
  │   ├── on every push ─► ci.yml                                            │
  │   │      ubuntu · Node 24 · npm ci                                       │
  │   │      playwright install chromium --only-shell                       │
  │   │      node --test   (offline suite ONLY — no live eBay ever)         │
  │   │                                                                      │
  │   │   ✓ checks: branch protection can require this on main              │
  │   │                                                                      │
  │   └── on every tag v* (or manual dispatch) ─► deploy.yml                │
  │          1) checkout                                                    │
  │          2) rsync code  --delete                                         │
  │                EXCLUDE node_modules/  (deps installed on VPS)            │
  │                EXCLUDE data/         (jobs + auth = state, not code)     │
  │          3) ssh VPS_USER@VPS_HOST                                       │
  │          4) sudo systemctl stop scamshield (clean stop)                 │
  │          5) sudo npm ci --omit=dev                                      │
  │          6) sudo bash scripts/vps_pre_deploy_gate.sh                    │
  │                (golden + render + canary on the VPS box,                 │
  │                 captures are rsynced once, outside git)                  │
  │             gate pass?  ─► continue                                     │
  │             gate fail?  ─► ABORT, leave previous tag running            │
  │          7) sudo systemctl start scamshield                             │
  │          8) smoke: curl /healthz + curl /                                │
  │                                                                          │
  │   rollback ladder = previous tag → re-deploy                             │
  └──────────────────────────────────────────────────────────────────────────┘

  Required secrets (GitHub repo → Settings → Secrets):
    VPS_SSH_KEY      private half of the deploy keypair (ed25519)
    VPS_HOST         hostname
    VPS_USER         ssh user (scamshield or a dedicated deploy user)
    VPS_GATE_TOKEN   (optional) shared secret on the gate script

  The deploy user on the VPS can ONLY: read app code, restart the unit,
  write under /opt/scamshield/app.  No sudo beyond the systemctl + npm +
  scripted gate.  SSH key is dedicated (revocable alone).
