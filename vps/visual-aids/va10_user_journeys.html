1. HAPPY PATH (THE DEMO)
   ┌─ Judge opens the app
   │   ↓
   │  Types "rtx 3090" → submit
   │   ↓
   │  Live SSE progress:
   │    :stage capture → :stage facet current {cards, target, scrolls}
   │    :stage facet completed {sign_in_required}     ← honest outcome
   │    :stage facet sold {sign_in_required}          ← honest outcome
   │    :stage decode → :stage extract → :stage analyze → :stage report
   │   ↓
   │  :done {reportUrl} → "Open report →"
   │   ↓
   │  Report loads:  faceted sidebar · summary band · spectrum chart
   │   ↓
   │  Judge cross-filters facets, opens listing drawers, narrows the
   │  sold window, reads the price band and scam-zone cutoffs.
   └─

2. BLOCKED
   honest typed error card 'blocked' + Retry (re-POST)
   provenance kept on disk (captures, JSONL sidecar, console messages)
       └─ proof to the operator: nothing lied

3. NO RESULTS
   "No exact matches on eBay for …"  →  fix query, resubmit
       └─ never a silent empty report

4. REVISIT / SHARE
   reports persist at /report/{id}/          ← stable URL
   home page Recent reports list reopens any   ← demo-day fallback if live run was blocked
   past report (byte-identical assets; only data.js varies per job)

5. BUSY
   second submit while running  →  "an analysis is already running —
                                    watch its progress →"  (409 with wait affordance)

6. CONNECTION DROP
   SSE auto-reconnect + event-log replay from job.json
   polling fallback (/api/jobs/:id/status) if EventSource errors
   job completes server-side regardless of any client drop

7. JUDGE
   Landing page tells the story
       → live run (or pre-captured)
   Self-guided exploration
       → fully explainable report (every facet outcome visible in META)
