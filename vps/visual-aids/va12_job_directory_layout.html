   REPLAY INVARIANT — useful invariant:
     delete everything except job.json + captures/
     → 'cli.js replay --dir <job>' still regenerates dataset → analysis → report
       with ZERO browser and ZERO eBay contact.

   PRIVACY BOUNDARY — careful here:
     The router only serves files under jobDir/report/.
     captures/, dataset.json, relevance.json, analysis.json are unreachable
     from HTTP by construction.
     data/auth/profile is OUTSIDE the job tree, 0700 dir + 0600 files.

   PRUNING — bounded growth:
     pruneJobs(keep=20) drops oldest jobs entirely (captures included).
     Backups carry the long tail.
