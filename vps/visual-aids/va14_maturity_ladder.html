Maturity ladder — what each level buys you, what it costs
─────────────────────────────────────────────────────────

M0 = L1 + L2 + L8 + L9      ← credibly-locked-down VPS + Apache reverse proxy + AutoSSL
    • ed25519 SSH key, password auth off
    • cPanel subdomain on HTTPS, never :8787 directly
    • Apache proxies /, public entry only via :443
    cost: ~3 hours; what it stops: drive-by port scans, password brute force

M1 = M0 + L11 + L12         ← production baseline
    • tag-based CI/CD (L10) — every change is a tag, every tag is reversible
    • backups nightly + the restore drill written down
    • the morning-of runbook, the rehearsal
    • status.sh returns 7 [OK] lines
    cost: ~6 hours; what it stops: "we made a change at 2am and now nothing works"

M2 = M1 + L18               ← enterprise hardening (security review-ready)
    • fail2ban jails (SSH + app + API)
    • audit chain (HMAC, tamper-evident)
    • systemd-creds for secrets (no plaintext env vars in the unit file)
    • weekly security smoke; oscap audit clean-ish
    cost: ~8 hours; what it stops: "show me your security posture" questions,
          credential-leak blast radius

M3 = M2 + L17 + Vault       ← multi-VM + secret vault
    • 1 LB + 2 web + 1 data; HAProxy at the front
    • shared data-tier (NFS or distributed rsync)
    • secrets in HashiCorp Vault (lease semantics, dynamic creds, audit)
    • Terraform-managed
    cost: ~12 hours; what it stops: "we're a small fleet, but our security
          controls scale with us, not lag behind us"

M4 = M3 + full CIS + SOC 2  ← compliance certified
    • all M3 controls + CIS EL9 Level 2 baseline
    • ISMS documentation; SOC 2 Type 2 evidence
    • capacity for regulated industries
    cost: ~30+ hours; what it stops: enterprise procurement
