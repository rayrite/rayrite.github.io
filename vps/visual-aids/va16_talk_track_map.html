The 2-minute version (the default)
─────────────────────────────────────
00:00 · "ScamShield answers: is this eBay listing priced like the real market,
        or like a trap? You type the query; the app drives a real browser
        through 3 search facets; captures each as forensic evidence (SHA-256,
        timestamped); parses offline; serves an interactive faceted report.
        We never fake success."
00:15 · Type "rtx 3090" → submit
00:20 · Live SSE timeline (narrate each stage):
        capture → facet current → facet completed {sign_in_required}
        → facet sold {sign_in_required} (the wall, called out)
        → decode → extract → relevance → analyze → report → done
01:25 · "Here's the report URL → "
01:50 · Take the click → show the faceted dashboard
        (sidebar · summary band · spectrum chart)
02:30 · STOP.  Wait for the question.

The 4-minute version (the standard)
─────────────────────────────────────
00:00 · Same opening (15s)
00:15 · "Before we run live, here's the proven reference"
        (open Recent reports → pre-captured fallback)
01:15 · Run the live demo (60s)
02:15 · Show VA-03 (data flow) + VA-04 (runtime sequence)
        (1024px display, ~15s talk)
03:00 · The non-adoptions brief (45s):
        "One runtime dep: Playwright.
         No DB — files are the store.
         No stealth — wall is authentication, not detection.
         No automated sign-in — human does every trust event."
03:45 · Click the demo out — filter a facet, open a drawer
04:00 · STOP.

The 8-minute version (the deep cut)
────────────────────────────────────
All of the 4-minute, plus:
04:00 · Show profiles/rtx-3090.json (90s):
        variants.dims, MSRP table, attributes.vramGb regex,
        relevance.exclude — pure data + first-match-wins
05:30 · Show VA-06 (facet state machine) — explain why we never
        waitForLoadState('networkidle'); eBay telemetry starves it
06:30 · Show the tag ladder in git:
        v0.0-meta → v0.1-scaffold → ... → v1.0-demo
        "every gate earns its tag; rollback is a tag push"
07:30 · "One more thing" → click into Recent reports → open an
        old job → switch back to live → close on the typed-error
        card if a wall hits (honest failure as closer)
08:00 · STOP.
